# magic-8-ball

## Chrome AI answers (optional)

When the app runs in a Chrome that has the built-in on-device model ready, a gear button appears in the top-right corner.
Its toggle switches the ball from the classic preset answers to answers generated by Chrome's built-in AI (Prompt API / Gemini Nano).
The choice is remembered in `localStorage`.

- AI answers keep the tones of the active answer set (affirmative / non-committal / negative, respecting the `af` filter).
- An AI answer may not be longer than the longest active preset answer; longer replies are re-requested, up to 3 attempts,
  after which the ball shows one of the classic "try again later" answers.
- If the model is not available (other browsers, or Chrome without the model), the gear button is not shown at all.

To enable it in Chrome, see [Chrome's Prompt API docs](https://developer.chrome.com/docs/ai/prompt-api): the device must meet
the hardware requirements and the model must be downloaded (its status is shown at `chrome://on-device-internals`).
